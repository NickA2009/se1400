D6

Rerolls all pedestal items in the room into other items. This can completely change a run and is one of the most powerful active items in the game. Basically you have the chance to change a really bad item into some of the best possible ones.

Void

Consumes pedestal items in the room and converts their effects into stat boosts or absorbs active item abilities. One of the most powerful scaling items in the game, allowing Isaac to stack multiple effects into one broken build.

Death Certificate

Allows Isaac to access a hidden room that contains every item in the game and lets the player choose one. It is one of the strongest items in the game because it guarantees access to any item you want, often creating completely broken runs.

R Key

Restarts the entire run while keeping all collected items and stats, essentially letting Isaac “reroll” the entire run into a stronger version of itself. It is extremely powerful for building unstoppable combinations over multiple runs.
